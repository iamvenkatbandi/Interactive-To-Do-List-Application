# Interactive To-Do List Application

A modern and responsive To-Do List Application built using HTML, CSS, and JavaScript. This application helps users manage daily tasks efficiently with features like add, edit, delete, complete task functionality, and Local Storage support for persistent task management.

---

## 🚀 Features

- Add New Tasks
- Edit Existing Tasks
- Delete Tasks
- Mark Tasks as Completed
- Local Storage Support
- Responsive User Interface
- Task Statistics Counter
- Empty Task Message
- Smooth Hover Effects
- Clean Modern UI Design

---

- JavaScript
